# Logical Levels

BindOS uses operational logical levels.

- L0: event or action
- L1: message
- L2: relational rule
- L3: meta-rule
- L4: context and participation

The key diagnostic question is:

> Is the conflict being solved on the same logical level on which it is generated?

A scene becomes structurally trapped when valid moves at one level are eliminated by constraints at another, while access to repair or exit is blocked.
