# Ontology

BindOS models relations, not personalities.

## Core entities

- Actor
- Event
- Message
- Interpretation
- Rule
- MetaRule
- Gate
- Sanction
- Context
- State

## Core distinction

A scene is not prose. It is a typed directed graph with an active context.

A pattern is not a diagnosis. It is a reusable relational topology.

A breakpoint is not advice. It is a point at which changing a node, edge, rule, gate, or frame changes the reachable state-space.

## Epistemic states

Every datum must be marked as one of:

- observed
- inferred
- suggested
