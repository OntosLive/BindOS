# Minimal Primitive Model

BindOS should resist ontology inflation.

The canonical primitive set is:

- Entity
- Relation
- Operator
- Channel
- Weight

Everything else is treated as a derived view unless evidence requires a new primitive.

## Derived structures

### Russell rank

Computed from the target chain of an operator.

### Transition cost

Computed from weighted influences on a move.

### Meta-level

Computed when an operator targets a relation or another operator.

### Hierarchy and dominance

Computed from directed asymmetry, reachability, reinforcement, and weight.

### Channel priority

Not stored as a universal hierarchy.

The same channel may dominate in one scene and be negligible in another. Priority emerges from effective weight in context.

## Compression principle

The model should be able to collapse a detailed layer into an effective parameter for another layer without changing the primitive ontology.

This is compatible with later coarse-graining or renormalization-style views, but the primitive kernel remains unchanged.
